# Python Developer Internship - Task 1

## Project
**Fundamentals and Setup – Hello World**

This starter repository demonstrates a basic Python program and documents the
development environment setup for Task 1 of the Python Developer Fresher internship.

## Prerequisites
- Python 3 installed
- Visual Studio Code installed
- Git installed (for version control)
- A GitHub account

## Run the program
Open a terminal in this folder and run:

```bash
python --version
python hello_world.py
```

On some Windows installations, use `py` instead:

```bash
py --version
py hello_world.py
```

Expected output:

```text
Hello, World!
Python development environment is ready.
```

## Suggested Git workflow
```bash
git init
git add .
git commit -m "Complete Task 1: Python fundamentals and setup"
```

Create a new **public** repository on GitHub (for example,
`python-developer-internship`) and follow GitHub's instructions to connect
this local folder and push the commit. Do not upload passwords, API keys,
personal documents, or other sensitive information.

## Learning outcomes
- Locate and run a Python script.
- Understand a basic Python function and the `__main__` entry point.
- Use VS Code as a code editor.
- Track project files with Git and publish a portfolio repository on GitHub.
